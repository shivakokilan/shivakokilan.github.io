# Sivagnanam Kokilan — ATS-friendly CV

A simple, semantic, single-column HTML CV suitable for publishing with GitHub Pages.

## Files
- `index.html` — CV content using standard headings, paragraphs and lists.
- `styles.css` — responsive and print-friendly styling.
- `resume.txt` — plain-text CV content for easy ATS parsing and copy/paste.

## Publish with GitHub Pages
1. Create a GitHub repository named `shivakokilan.github.io` (or another repository).
2. Upload `index.html`, `styles.css` and `resume.txt` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will show the published website URL.

## ATS notes
- The page uses a single-column reading order.
- It avoids tables, columns, icons, images, charts and text embedded in graphics.
- Headings use standard CV section names.
- Contact details and skills are selectable text.
- Keep a separate DOCX or PDF version for job applications if the employer's application portal requests an uploaded resume. A portfolio website is supplementary and does not replace the uploaded CV.

## Before publishing
Review all dates, employer names, metrics and contact links for accuracy. This page preserves the information supplied in the uploaded CV; it does not independently verify claims.
